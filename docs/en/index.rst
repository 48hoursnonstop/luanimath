luanimath
================================================================================

Write mathematical animations in Lua. Create vector objects, schedule motion,
shape Unicode text, import SVG, plot functions and render 2D or 3D scenes.

This manual covers the implemented library. The compatibility target is Manim
Community 0.22.1; the project is an early development port. Consult
:doc:`compatibility` before relying on upstream features that are not documented.
