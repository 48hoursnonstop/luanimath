luanimath
================================================================================

Escribe animaciones matemáticas en Lua. Crea objetos vectoriales, programa
movimientos, compón texto Unicode, importa SVG, representa funciones y renderiza
escenas 2D o 3D.

Este manual cubre la biblioteca implementada. El objetivo de compatibilidad es
Manim Community 0.22.1; el proyecto está en desarrollo temprano. Consulta
:doc:`compatibility` antes de usar funciones de upstream que no estén documentadas.
